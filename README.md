📘 Sistema de Gestão de Alunos – Documento de Visão

Este repositório contém o Documento de Visão do Sistema de Gestão de Alunos – PRIM21, desenvolvido como parte das atividades da disciplina de Projeto de Software (UDESC). O documento estabelece, em alto nível, a proposta, contexto, funcionalidades e requisitos essenciais do sistema.

🎯 Objetivo do Sistema

O sistema tem como propósito automatizar e centralizar a gestão administrativa de negócios baseados em agendamentos recorrentes, como academias, escolas, cursos e estúdios.
Ele busca eliminar controles manuais, reduzir falhas operacionais e oferecer uma experiência mais fluida tanto para administradores quanto para alunos.


🧩 Problema que o Sistema Resolve

Atualmente, administradores sofrem com:

Falta de centralização de dados

Planilhas manuais sujeitas a erros

Controle confuso de pagamentos e horários

O sistema foi projetado para oferecer simplicidade, organização e visualização clara, sem envolver transações financeiras.


👥 Stakeholders e Usuários

Administrador / Professor
Responsável pela gestão de cadastros, vencimentos e horários.

Aluno
Realiza cadastro, visualiza seus horários e gerencia reposições de aulas.


🏗️ Visão Geral do Produto

O Sistema de Gestão de Alunos é uma aplicação web responsiva, acessível via navegador, projetada para operar tanto em desktops quanto em dispositivos móveis.

Premissas:

Usuário deve ter acesso à internet

Não há integração financeira neste módulo


⚙️ Principais Funcionalidades

Cadastro de alunos com foto e dados pessoais

Controle de vencimentos

Agenda visual e gerenciamento de horários fixos

Cadastro autônomo pelo aluno

Interface moderna, responsiva e intuitiva


🔒 Requisitos Não Funcionais

Autenticação e controle de acesso

Boa performance e carregamento leve

Alta usabilidade, com foco em mobile

Arquitetura modular para evolução futura
